# HungDam_TraiTim

Tổng hợp code trái tim của HungDam_TraiTim.

Code được viết trên 2 ngôn ngữ HTML và PYTHON.

- HTML: mở trực tiếp các file `index.html`, `index2.html`, `index3.html`, `index4.html` bằng trình duyệt (hoặc dán vào https://www.w3schools.com/tryit/ và Run).
- PYTHON: chạy `python HungDam_TraiTim.py` (cần Python có sẵn tkinter).

## Bản web giống bản Python

`HungDam_TraiTim.html` là bản port 1:1 thuật toán của `HungDam_TraiTim.py` sang canvas, mở bằng trình duyệt là chạy. 4 file `index*.html` là hiệu ứng khác (trái tim hạt bay), không liên quan tới bản Python.
